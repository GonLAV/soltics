# לולאת העבודה — מלאכי

## בדיקת הרשאות (חובה, לפני כל שימוש חי)

```bash
# TOKEN מ-~/quad-meta-mcp/.credentials.txt (LONG_TOKEN=) או מקביל — קריאה בלבד, לא כותבת כלום
curl -s "https://graph.facebook.com/v19.0/me/permissions?access_token=$TOKEN" | python3 -m json.tool
```

מחפשים ברשימה: `pages_messaging` (פייסבוק), `instagram_manage_messages` + `instagram_manage_comments` (אינסטגרם). כל אחת חייבת status `"granted"`, לא רק מופיעה ברשימה — יש גם `"declined"`/`"expired"`.

**אם משהו חסר** — לא ממציאים workaround. אומרים בדיוק מה חסר ומפנים ל-App Dashboard (developers.facebook.com/apps/<APP_ID>/permissions) לבקש את ההרשאה, שדורשת בד"כ App Review של מטא (לא מיידי).

## הלולאה בכל הודעה

1. **קרא** — שלוף הודעות/תגובות ממתינות (endpoint קריאה, תמיד בטוח).
2. **נסח** — תגובה בקול QUAD. לא ממציא מידע עובדתי.
3. **הצג** — בלוק נפרד וברור:
   ```
   → לשלוח ל: [שם/מזהה]
   → ערוץ: [Instagram DM / Facebook Messenger]
   → טקסט:
   [הטקסט המדויק]
   ```
4. **עצור** — המתן ל"כן"/"שלח" מפורש. "אישרת קודם" לא נחשב.
5. **שלח** — קריאת API אמיתית, ורק אחרי אישור.
6. **אמת** — בדוק את קוד התשובה/status, דווח בהצלחה או בכישלון בפועל — לא הנחה ששליחה=הצלחה.

## מה לא לעשות אף פעם

- לא לשלוח "אצווה" של כמה הודעות מאושרות-מראש בלי לעבור אחת-אחת.
- לא לענות אוטומטית על הודעות חדשות שנכנסות תוך כדי השיחה בלי להציג אותן קודם.
- לא לפרסם תוכן (פוסט/סטורי) — זה תמיד עובר דרך אותה לולאת אישור, גם אם "רק טיוטה קטנה".
