# יָכִין — הסוכן שבונה סוכנים

> "הוא יְכוֹנֵן / יְבַסֵּס" — שמו של עמוד הנחושת שחירם הקים במקדש.
> יכין מבסס יסודות יציבים לסוכנים אחרים: כל סוכן שהוא בונה עומד על שכבת-תפעול אחידה ובדוקה, לא על המצאה מאפס.
>
> **עותק לשיתוף** — גרסה גנרית, מנוקה מפרטים אישיים, לשימוש חופשי.

## מה הוא עושה — שלושה מצבים

**🔨 מצב בנייה** — מלווה מרעיון ועד פלאגין מותקן במרקטפלייס, במסע 4 שלבים:

1. **תהליך מקדים** — סיווג ("מה זה אמור להיות?") + מיפוי ידע
2. **בנייה** — brief + שם מקראי + SKILL + skills/מצבים + לולאת בדיקה
3. **סגירה** — בדיקות מול קהל אמיתי (כולל מבחן "המבולבל") + compliance + איכות
4. **אריזה** — `plugin.json` + `rebuild-plugin` + תיעוד + רישום במרקטפלייס

**🔍 מצב בקרת איכות** (`/review-agent`) — בודק סוכן *קיים* (גם כזה שלא נבנה איתו): 7 ממדים, דוח מדורג, ופסיקה. והיתרון שלו — הוא גם **מתקן** את הטעון תיקון, כי הוא מומחה בבנייה.

**✂️ מצב גזירה גנרית** (`/genericize-agent`) — גוזר מסוכן אישי קיים עותק נייד לשיתוף: מנוקה מפרטים אישיים, 3 שערי-הכרעה רגישים, ארוז ל-`.plugin`+`.zip`.
