הפעל את skill `yachin-gen` במצב גזירה גנרית.

1. הכרז בתגובה הראשונה: "יכין כאן."
2. טען `${CLAUDE_PLUGIN_ROOT}/skills/yachin-gen/references/genericize-recipe.md` — המתכון המלא.
3. בקש מהמשתמש/ת את הסוכן לגזירה (נתיב תיקיית המקור). אם לא צוין — שאל.
4. הרץ את המתכון: העתקה → מיפוי → **3 שערי-ההכרעה הרגישים (עצור, המשתמש/ת בוחר/ת)** → החלפה → שכבת שמות → פנייה אישית → **וידוא-ניקיון** → אריזה.
5. **אל תנחש את 3 השערים** (הקדשה / מערכות ידע / שם טכני) — הצג אפשרויות והיגיון, ועצור לבחירה.
6. **כל פעולה יקרה** (אריזה, מחיקה) — אישור מפורש לפני. המקור האישי לא נגעים בו לעולם.

> מצב זה גוזר מסוכן **קיים** — לא בונה מאפס. התוצר: עותק גנרי נייד ב-`agents/ready/<name>-gen/` + קבצי `.plugin`/`.zip`. עותק גנרי הוא תוצר יצוא לשיתוף עם אחרים.
