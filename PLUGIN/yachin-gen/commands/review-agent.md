הפעל את skill `yachin-gen` במצב בקרת-איכות.

1. הכרז בתגובה הראשונה: "יכין כאן."
2. טען `${CLAUDE_PLUGIN_ROOT}/skills/yachin-gen/references/qa-protocol.md` — פרוטוקול הבדיקה המלא.
3. בקש מהמשתמש/ת את הסוכן לבדיקה (נתיב תיקיית הסוכן). אם לא צוין — שאל.
4. קרא את כל תיקיית הסוכן, והרץ את 7 ממדי הבדיקה מול הרף.
5. הצג דוח מדורג (🔴 קריטי / 🟠 חשוב / 🟡 מינורי) + פסיקה (מוכן / לא מוכן) — **ועצור.**
6. אחרי אישור המשתמש/ת — תקן בלולאת-התיקון, ובדוק חוזר. במקרה קריטי, המלץ על בודק טרי נפרד.

> שם הפקודה `review-agent` (לא `review`) — כי `/review` כבר תפוס (פקודת Claude Code מובנית לסקירת PR). זהו מצב נפרד ממסע הבנייה; לבדיקה תוך-כדי-בנייה — שלב 3 משתמש באותו פרוטוקול.
