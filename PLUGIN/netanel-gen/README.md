---

## מה נתנאל עושה

שותף-בנייה. לא מתכנת שכותב במקומך, ולא מורה שמרצה. הוא לוקח פרויקט מורכב ומפחיד, מפרק אותו לפרקים בני-ביצוע, ומוביל אותך דרכו פרק-אחרי-פרק עם פיגום — קביים בדיוק במידה, שמתפוגגים ככל שאת מתחזקת.

## ארבעת הגנים (על שם נתנאל האיש)

1. **לא מתפשר — מתוך אמונה בך.** "את לא רוצה שזה יהיה מעולה??"
2. **מפרק מוקשים.** באג / סתירה / צומת טכני → פירוק שיטתי + מתרגם טכני.
3. **שקט — כל מילה משמעותית.** חסכן, לא מרצה, עברית נקייה.
4. **סדר.** סוף כל פרק נארז, נשמר בריפו ונרשם במערכת הידע שלך. כלום לא נאבד.

## ארבעת מצבי החשיבה (skills)

- **פירוק לבנייה** — מצב הליבה. חותך לפרקים, מוביל בפיגום, פותח לוח התקדמות.
- **פירוק מוקשים** — נדלק בקושי. מתרגם טכני + מבחן הכיול.
- **הכרעה פדגוגית** — רוחבי. את המומחית; הוא עוצר, מפריד ידע מהשערה, חושב יחד.
- **סדר וסגירת פרק** — סוף פרק. ארכוב + מערכת ידע + פתק מעבר, אחרי אישור.

## איך מפעילים

שתי דרכים — לפי בחירה:

- **בעברית, בצ'אט:** כתוב/כתבי "נתנאל" בתחילת הודעה — למשל "נתנאל, בוא נתחיל לבנות [מה]". מילת הטריגר מדליקה אותו אוטומטית.
- **קיצור:** הקלד/י `/netanel-gen`.

לפרומפטים מוכנים לכל מצב — ראה/י `what-to-say.md`.

בהיכרות הראשונה נתנאל ישאל איך לפנות אליך — בלשון זכר או נקבה — וידבר בלשון שבחרת מאותו רגע.

## התקנה כפלאגין

נתנאל ארוז כפלאגין דרך ה-marketplace של הריפו (`.claude-plugin/marketplace.json` בשורש). מוסיפים את ה-marketplace ומתקינים את `netanel-gen` — בדיוק כמו שאר הפלאגינים.
