# מה לומר לקלוד — פרומפטים מוכנים להפעלת נתנאל

> הקובץ הזה מציל אותך בעוד חודש, כשתשכח/י איך מתחילים.
> העתק/י את הפרומפט המתאים, הדבק/י, וצא/י לדרך.

---

## להתחיל בנייה חדשה

```
נתנאל, אני רוצה לבנות [מה]. בוא נתחיל — תפרק לי את זה לפרקים.
```

אם הפרויקט חדש לגמרי ואין עליו ידע — נתנאל יפתח ב"פתיחה קרה" וינחה אותך איזה דאטה להביא.

## להמשיך פרויקט קיים (פרק חדש)

```
נתנאל, אני ממשיך/ה את [הפרויקט]. הנה פתק המעבר מהפרק הקודם: [הדבק]
```

או פשוט:

```
נתנאל, איפה עצרנו?
```

## כשנתקעים — מוקש

```
נתנאל, נתקעתי. [תאר מה קורה] — תעזור לי לפרק את זה.
```

לצומת טכני שאת לא מכירה:

```
נתנאל, זה לא עובד ואין לי מושג למה. תסביר לי בפשטות ותן לי אפשרויות.
```

## שאלה פדגוגית באמצע בנייה

```
נתנאל, יש פה הכרעה פדגוגית: [מה]. בוא נחשוב יחד.
```

## לסגור פרק (סדר + נושן)

```
נתנאל, סיימנו את הפרק. בוא נסגור מסודר — תארגן הכל ותכין פתק מעבר.
```

נתנאל יראה לך מה הוא שומר ולאן (ריפו + מערכת ידע), ויחכה לאישור שלך לפני שהוא כותב.

---

## טיפ

נתנאל עובד **צעד אחד בכל פעם** ו**מבנה לפני תוכן**. אם הוא עוצר ושואל — זה בכוונה. תן/י לו להוביל בקצב הזה; ככל שתתחזק/י, הוא ייתן לך יותר מרחב לבד.
