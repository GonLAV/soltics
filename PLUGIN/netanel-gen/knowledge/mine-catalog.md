# ספר המוקשים — קטלוג גנרי

> נכס-שיטה נייד. קטלוג מוקשים שגדל וחוצה פרויקטים. כל מוקש שנפתר נכנס לכאן — כדי שלא ניתקע בו פעמיים.

---

## עקרונות פירוק מוקש (מהמקצוע של נתנאל האיש)

1. קודם לא נבהלים — מרגיע, אחר כך פועל.
2. מבודדים את השטח — מגדירים בדיוק מה הבעיה ואיפה.
3. מבינים את המנגנון לפני שנוגעים — קודם *למה*.
4. חוט אחד בכל פעם — שינוי, בדיקה, המשך.
5. יודעים מתי לא לחתוך לבד — מזהים מתי להביא גיבוי.

---

## רשומות

### מוקש #1 — ייצוא לייאאוט מורכב: SVG, לא PDF
**הופעה:** ייצוא של לוח/פריסה מורכבת נראה שבור — כל המראה התעוות.
**מנגנון:** ב-PDF הפריסה נצרבת ומתעוותת בלייאאוטים מורכבים. SVG שומר וקטור — כל אלמנט נשאר במקומו.
**פתרון:** לייאאוט מורכב לייצוא → SVG (או PNG לתמונה סטטית), לא PDF.
**מקדים תרופה:** כשמגיעים לייצוא של משהו עם פריסה עשירה — לבחור SVG מראש.

### מוקש #2 — "ריפו בתוך ריפו"
**הופעה:** סיבוכי git — תיקיית פרויקט שמכילה ריפו משלה בתוך ריפו אחר.
**מנגנון:** git מתבלבל כששני ריפואים מקוננים; commits ו-tracking מתנגשים.
**פתרון:** לסדר את מבנה ה-git לפני שממשיכים לבנות — להחליט מי הריפו הראשי, לא לקנן.
**מקדים תרופה:** בתחילת פרויקט חדש — לבדוק שאין ריפו מקונן בטעות.

---

> רשומה חדשה מתווספת בכל פעם שנתנאל פורק מוקש חדש. הפורמט: הופעה → מנגנון → פתרון → מקדים תרופה.
